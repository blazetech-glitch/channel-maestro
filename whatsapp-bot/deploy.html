Deploy to Heroku

One click sends the WhatsApp Channel Auto-Post Bot to Heroku, and Heroku asks you for the required settings (admin login, channel ID, etc.) during setup.

The repo must contain the whatsapp-bot folder on the main branch.

Enter your repository as username/repo first.

Deploy to Heroku
Before you click:
1. Connect this project to GitHub (Lovable editor: + menu → GitHub) so the code is on GitHub.
2. Come back here, type username/repo above, and click the button.
3. On Heroku's form, fill in ADMIN_USERNAME, your admin password, and CHANNEL_JID (your channel's …@newsletter id).
4. After deploy, open the app, log in, and scan the WhatsApp QR code once.
